# Flow Fields & Chunked Spatial Optimization

*Note: This repository is for exploring procedural generation and algorithmic optimisation.*

**Author:** Ana Paoliello de Lucena Carvalho  
**Project Mission:** The goal of this project is to research the mathematics behind procedural vector Flow Fields and implement "chunking" algorithms. By dividing the environment into loaded/unloaded chunks, this simulation aims to achieve infinite, highly optimised generative spaces without sacrificing frame-rate performance.
